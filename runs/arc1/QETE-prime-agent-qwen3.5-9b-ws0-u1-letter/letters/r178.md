**Rule families that recur — learn to recognize them**

- **Stamping/copying**: one large "seed" object gets stamped at every smaller object's location (anchor = seed bbox center, or cell center). See task-1b7868f1.
- **Twin selection**: among pairs of identical shapes, recolor one based on distance to a special object (task-0f6e5a2f).
- **Fill between markers**: background gaps between same-color markers in a row/column get a fixed color (tasks-8625f9bc, b7641a67, 5c839a47). Variants: "strictly between min and max dot," "gaps of size ≤ 2," "runs on diagonals extend" (task-3b5f776f).
- **Grid division**: full uniform separator rows/cols split the grid into blocks; output is one value per block (odd stray count → 1, task-48898d06; 4-corner markers equal → their color, task-bb30ebc2).
- **Comparison of two halves**: split by a centered separator; output cell compares the two halves (equal → 3 or 2, task-026adbf3, task-707635df).
- **Symmetry/tiling**: output = input composed with rotations/mirrors (task-794e60f6: TL+rot90/rot270/rot180; task-73499f5a: mirror-rows, tripled with reversal; task-2e29965a: periodic tiling by anti-diagonal).
- **Object relocation**: shape shifts to touch a full line; old spot becomes background; a marker line is drawn at the old position (task-77262100).
- **Enclosed regions**: flood-fill background regions not touching the border; fill them (task-3f4fb1a9, aa5a69a0, b62da9e0 — b62da9e0 keeps only components ≥3 cells and keeps their bboxes).
- **Bbox perimeter / projections**: draw lines through markers (d4079843: stub toward nearest bar, mirror on the other bar).
- **Row/column uniformity**: any row or column that is a single color gets recolored (task-47ed202e → all 2).
- **Shifts**: everything shifts down one row (efc2fba8).

**Practical heuristics**

- Always compute the background first (most common color). Most rules are "everything else" relative to it.
- Use connected components (both 4- and 8-connectivity — check which fits the demos) with bounding boxes, sizes, and canonical shape keys (sorted normalized cell tuples) for matching twins.
- Verify symmetric structures: full separator lines, centered lines (2*r+1 == H), uniform rows/cols.
- When output size differs from input, look for the pattern early: halves, thirds, 3×3 downscaling (task-67dd046a: one cell per 3×3 block = mode excluding color 5).
- Write code that fails loudly (raise) when the expected structure is missing rather than returning a silent wrong answer.
- Keep a memory file per task with the one-line rule and "reproduces_all" status. The moment your program reproduces all kept demos, save it — do not keep "improving."
