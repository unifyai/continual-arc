# Results

Runs submitted to the [Continual-ARC leaderboard](https://unify.ai/continual-arc/leaderboard), one directory each:
`<track>/<name>/` holds the run directory the benchmark's runner wrote (`records.jsonl`, `summary.json`,
`schedule.json`, `config.json`, `meta.json`) and a `submission.json` that names it. How to run, check and submit one
is in the [README](../README.md#submitting-a-result).

The paper's own 257 runs are not repeated here: their records are attached to the
[v0.1.0 release](https://github.com/unifyai/continual-arc/releases/tag/v0.1.0), and the leaderboard opens with them.
