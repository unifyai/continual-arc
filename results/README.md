# Results

Runs submitted to the [Continual-ARC leaderboard](https://unify.ai/continual-arc/leaderboard), one directory each:
`<track>/<name>/` holds a run directory the benchmark's runner wrote (`records.jsonl`, `summary.json`,
`schedule.json`, `config.json`, `meta.json`): a learner's stream, with a `submission.json` that names it and the
directories of its two frozen tests, their references and the demo-cache floor's runs. How to run, check and submit
one is in the [README](../README.md#submitting-a-result).

The paper's 198 runs on GPT-6 Luna are not repeated here: their records are attached to the
[v0.1.0 release](https://github.com/unifyai/continual-arc/releases/tag/v0.1.0), and the leaderboard opens with them.
